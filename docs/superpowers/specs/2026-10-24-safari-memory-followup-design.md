# Safari 메모리 원인 재검토 및 후속 수정 설계

작성일: 2026-10-24. 상태: 후속 실행 승인. 분석 도구 구현 및 네 어댑터 native 성공 정렬 300회·종료 분석 수행. Vue 입력 제한 및 native DOM 보유 귀속을 추가 검증하며 전체 자원 판정은 미완료.
기준: `4fcdba1e40c8aaa387611f559780c571e2b1b851`, Safari 27.0.1.

## 목표와 범위

브라우저 검사 과정에서 보유되는 객체와 제품 소유 객체를 구분하고, 남은 장기 드래그 증가의 원인에 따라 최소 수정한다. 최초 산출물은 계획이었다. 후속 실행 승인에 따라 분석 도구·회귀 검사·대조군을 구현하고 native 반복 검증을 진행한다. 원격 작업은 포함하지 않는다.

공개 API, export, 의존성, 버전, 라우팅 동작을 유지한다. 키보드 정렬, 3D, 프레임워크 API, FPS 검증은 이 메모리 계획에 포함하지 않는다. native Safari 증거를 Chromium/WebKit 결과로 대체하지 않는다.

`Document +25`는 raw JS 클래스 개수이며 native 문서 25개 생성의 증거가 아니다. 추가 객체는 Reader 실행 컨텍스트의 prototype/wrapper 패턴이다. flags의 internal/object/element 비트와 dead 상태를 혼동하지 않는다. Inspector 재연결 전후의 ID는 비교하지 않는다.

이번 검토에서 원본 3개를 다시 집계했고, 원본·후보 자산·분석 스크립트 manifest 11개 해시가 일치했다. 이는 기존 증거 재검토이며 새로운 장기 Safari 실행 결과가 아니다.

## 선택지와 권고

1. **검증·판정 보완 후 조건부 제품 수정 — 권고.** 관측된 Reader 컨텍스트와 제품 소유 자원을 분리한다. 현재 근거와 부합하며 실제 제품 결함이 발견되면 해당 유지 경로를 수정할 수 있다.
2. **URL 변경을 줄이는 Playground 우회.** 원인이 제품 없이도 재현되고 URL·뒤로가기 계약을 바꾸므로 현재 채택하지 않는다.
3. **Core/어댑터 정리를 선제 변경.** 제품의 추가 보유 경로가 확인되지 않아 현재 채택하지 않는다. 기존 cleanup/예외/재진입 계약에 불필요한 회귀를 만들 수 있다.

후속 사용자 승인으로 권고안의 실행에 착수했다. 이미 수정한 SessionMachine 이력 및 완료 disposer 문제를 이번 증거만으로 재발로 판정하지 않는다.

## 판정 계약

- 같은 브라우저·소스·자산·Inspector 세션 안에서 워밍업 전후와 반복 배치를 비교한다. 수집기가 제품 객체를 보유하지 않도록 객체 콘솔 출력·전역 참조·무제한 이벤트 로그를 추가하지 않는다.
- 클래스 수와 총 힙만으로 PASS를 만들지 않는다. 검사 대상 ownerDocument/area/instance, 종료 전후 ID, 객체의 retainer와 소스 위치를 함께 기록한다.
- 실제 드래그마다 시작 area/item, 목적지, 최종 순서, 종료 사유, 임시 marker 정리를 확인한다. reset/remount로 장수 scope 증가를 숨기지 않는다.
- 종료된 대상 runtime의 제품 인스턴스와 제거된 UI의 제품 소유 강한 참조는 0이어야 한다. 사용자 보유 handle 및 다른 살아 있는 runtime은 구분한다.
- native DOM/리스너 관측 수단이 없으면 미검증으로 남긴다. JS wrapper 수를 native DOM 수로 환산하지 않는다.
- 총 힙이나 코드가 증가하는데 귀속 또는 평탄화가 미확인이면 INCOMPLETE이다. 대조군 총량을 단순 차감하거나 기존 Chromium 1MiB 허용치를 Safari 합격 기준으로 복사하지 않는다.

## 산출물과 완료 경계

재현 가능한 분석 도구·수집 절차, 대조군, warm-up 이후 반복 증거, 제품 변경 필요 여부를 남긴다. 제품 누수가 확인되면 실패 회귀→최소 수정→영향 게이트를 거친다. 확인되지 않으면 제품 변경 없이 그 제한적 결론을 기록한다. 해결되지 않은 증가 또는 자원 관측 누락은 전체 메모리 PASS로 표시하지 않는다.

로컬 상세 원본은 ignored `.local/native-safari-followup-2026-10-24/`에 보존되어 있으며, 그 안의 `sol-high-analysis/REPORT.ko.md`가 분석 경위와 한계를 설명한다. 공유 문서에는 heap 원본·개인 경로·외부 페이지 데이터를 복사하지 않는다.
