Capture loss followed by document pointerup, callback errors, active external
state changes, unregister/unmount and destroy remain covered by their existing
termination and rollback contracts. These checks are not all newly fixed bugs
or new public features.

cycles each, including nested movement and runtime unmount/remount. The
placeholder-relocation regression captures the first rendered destination frame,
