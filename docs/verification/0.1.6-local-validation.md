## Fixes / 실제 수정

| Fix | Previous behavior | Candidate behavior |
| --- | --- | --- |
| Transformed move feedback | A fixed-containing-block ancestor could apply offsets/scales again, moving the card away from the pointer. | Keep viewport position and measured dimensions in tested translation, scale, planar rotation, filter and containment cases; re-anchor after ancestor scrolling. |
| Placeholder relocation | Moving the placeholder resized a scaled/rotated list and changed its percentage transform origin after coordinate correction. A single frame shifted by about 3.65–3.70px. | Re-anchor after placeholder placement in the same frame; the desktop Chrome rotation/scale check recorded about 0.004px maximum position error. |
| Detached copy/table preview | Inherited min/max dimensions and different source/body scales changed preview size. | Fit the preview in its parent's coordinate basis and remove clone-only dimension clamps. Preserve source styles and copy callback contracts. |
| Development dependency | source-map-js 1.2.1 was affected by GHSA-68fv-2mgg-jv7q. | Use patched 1.2.2 in the development lockfile; add no runtime dependency. |

- 원본 항목의 DOM 부모와 소비자 스타일을 유지합니다. 복제 데이터·ID를 만드는
  `copyItem`/`copyElement` 계약은 변경하지 않습니다.
- 회전 검증은 CSS `rotate()` 조건의 좌표 검사입니다. 모바일 세로·가로 전환
  기능이나 실기기 검증을 뜻하지 않습니다. 이번 순간 편차는 회전 없는 scale
  조건에서도 재현하여 수정했습니다.
- 공개 API, 선택적 peer, package exports, 런타임 의존성 0개 경계는 유지합니다.

## Verification expansion / 검증 보강

Capture loss followed by document pointerup, callback errors, active external
state changes, unregister/unmount and destroy remain covered by their existing
termination and rollback contracts. These checks are not all newly fixed bugs
or new public features.

Four adapter resource checks use 20 warm-up and 100 measured cancel/drop/reset
cycles each, including nested movement and runtime unmount/remount. The
placeholder-relocation regression captures the first rendered destination frame,
so a later pointer event cannot conceal the defect. It adds 24 cases across
Vanilla, React, Vue, Svelte and Chromium, Firefox, WebKit.

포인터 캡처 상실·외부 상태 변경·callback 오류·영역 해제와 destroy를 검증했습니다.
테이블 태그 검사는 fixture이며 공개 테이블 예제가 새로 추가된 것은 아닙니다.

## Desktop Computer Use / 실제 조작

After all automated gates passed, desktop Chrome/React was operated with native
mouse input on the actual Playground. A local wrapper applied consumer CSS and
observed the DOM without synthesizing drag/drop or changing application models.

Seven scenarios passed: rotation+scale move, scale-only move, scaled copy,
body/source nested-scale copy, containment, filter and ordinary move. Each
confirmed source `todo/design`, live destination `done`, final DOM order,
`afterDrag(drop)` and zero remaining drag/placeholder nodes. Copies retained
source Design and created `design-copy-1`.

After moving Design, native body selection and Chrome Copy followed by native
paste into a local input produced exactly `Design`. No additional sortable drag
started. Computer Use checks DOM evidence; internal model/DOM equality is
established separately by E2E.

이번 직접 검증에서 발견됐던 순간 편차는 해소됐습니다. 이전 미확인 본문 복사도
네이티브 붙여넣기로 확인했으며, 텍스트 선택 관련 제품 코드를 추가로 바꾸지는
않았습니다. 스크린샷은 조작 후 화면이고, 프레임별 좌표는 별도 관측 기록입니다.
