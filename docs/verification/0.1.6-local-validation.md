## Defects fixed / 실제 수정

| Change | Before | Candidate behavior |
| --- | --- | --- |
| Move-feedback coordinates | A CSS `transform`/containing-block ancestor could apply its offset a second time, shifting the dragged item away from the pointer. | Correct viewport/local coordinates for tested translation, scale, planar rotation, filter and containment cases. Re-anchor after ancestor scrolling; retain the original item parent and restore styles. |
| Detached-preview size | Inherited CSS min/max dimensions or different body/source scales could enlarge a copy/table preview. | Fit the measured viewport size in the preview parent's coordinate basis and remove clone-only min/max clamps. |
| Development dependency | `source-map-js` 1.2.1 was affected by GHSA-68fv-2mgg-jv7q. | Lock development-only source-map-js at patched 1.2.2; no runtime dependency is added. |

- **드래그 좌표:** transform 조상의 offset이 중복되어 카드가 포인터에서 벗어나는
  결함을 수정했습니다. 조상 스크롤 후에도 위치를 보정하며 원본 DOM 부모와
  소비자 스타일을 유지합니다.
- **복제 표시 크기:** CSS 최소·최대 크기 제한과 body/source의 서로 다른 scale로
  preview가 커지는 문제를 수정했습니다. preview만 보정하고 원본 항목을
  변경하지 않습니다. 복제 데이터·ID를 만드는 callback 계약은 유지합니다.
- **개발 의존성 보안:** source-map-js를 1.2.2로 갱신했습니다. Sortable 배포
  패키지에 런타임 의존성을 추가한 변경은 아닙니다.

## Verification added / 검증 확대

These are regression/resource checks, not new public features or claims that
all of these scenarios were previously broken.

- Pointer capture loss followed by document pointerup completes the gesture;
  callback errors, active external-state changes, unmount and destroy retain
  their existing rollback/termination contracts.
- Every adapter receives repeated cancel/drop/reset and nested runtime
  unmount/remount resource checks: 20 warm-up and 100 measured cycles each.
- Geometry checks include actual pointer-source/destination evidence,
  committed model/DOM order, cancellation and cleanup. Table-tagged cases are
  fixtures; no public table Playground route was restored.

포인터 캡처 상실·외부 상태 변경·callback 오류·영역 해제·destroy 및 반복 자원
검사를 보강했습니다. 이 항목들을 전부 새로 수정한 버그나 신규 API로 분류하지
않습니다. 공개 API, 선택적 peer, package exports, 런타임 의존성 0개 경계는 유지합니다.
