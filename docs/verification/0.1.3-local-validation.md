## Behavior and scenarios

| Scenario | Checked result |
| --- | --- |
| Select Build, press Reset, then Shift-click Review | All four adapters clear selected IDs, styling, and the old range anchor. Only Review is selected and moved on the next drag. |
| Select body text after moving Review | The text remains selectable. The latest direct check selected part of the label; it did not test clipboard paste. |
| Drag to the scroll container's bottom padding outside the registered drop area | Insertion feedback hides while the move placeholder retains its space and scroll range. Releasing outside cancels without changing the order. |
| Reenter a valid destination | Feedback returns and releasing commits the intended order. Escape cancels and removes temporary feedback. |
| Use custom or skeleton placeholders | Outside hiding, reentry, drop, and cancel preserve the same behavior. |

일반 데이터 갱신의 선택 유지 동작은 그대로이며 Playground의 명시적 초기화에서만
등록을 다시 생성합니다. 드롭 판정 영역과 자동 스크롤 속도 계산은 이번 두 수정에서
변경하지 않았습니다. 사용법은 [고급 정렬](../ko/16-advanced-sorting.md),
[자동 스크롤](../ko/10-animation-auto-scroll.md),
[Placeholder](../ko/13-placeholder.md)를 참고합니다.
