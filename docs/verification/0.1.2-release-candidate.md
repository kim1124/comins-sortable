## 실제 Safari와 입력 경계

2026-09-11에 실제 macOS Safari 26.6.2에서 Vanilla·React·Vue·Svelte 각각의
카드 이동 → `Desi` 부분 선택 → Cmd+C/Cmd+V → 빠른 재이동을 확인했다.
실제 마우스·키보드를 사용했고 Selection API로 선택을 주입하지 않았다.

이는 확인한 흐름의 증거다. Safari 전체 기능 인증, Safari의 보조키를 누른 채
클릭하는 입력, 실제 터치·펜 기기 인증까지 포함하지 않는다. Playwright WebKit
통과 역시 실제 Safari 검증을 대신하지 않는다.

원인·회귀·Safari 절차는 [드래그 수정 기록](../../reports/2026-09-11-native-drag-ci-fix.md)을
참고한다. [이전 테스트 누락 분석](./0.1.2-test-gap-audit.md)과
[성능 조사](./0.1.2-performance.md)는 당시 실패와 측정값을 보존한다.

## 배포 파일과 남은 단계

런타임 수정 후 만든 tarball은 파일 목록·라이선스·export·추출 Gitleaks 검사와
동일 파일의 최소 지원 peer consumer 검사를 통과했다. 기존 파일의 SHA-256은
`c77d883dea06b78d5f456ef157201c7414fc3a34ee08d5366fa0d460ffd37df2`다.

이번 README·CHANGELOG 갱신은 npm에 포함되는 파일을 바꾸므로 기존 tarball을
최종 배포 파일로 재사용하지 않는다. 문서 갱신 후 별도로 생성한 파일은
`fdf1d894a65fed1bdffb71856b1ef7633f4b846f503d4f92453cd7b565885268`이며,
파일 목록·라이선스·export·추출 Gitleaks와 동일 파일의 최소 지원 peer consumer
검사를 통과했다. 추출한 README·CHANGELOG·dist가 현재 파일과 일치함도 확인했다.

문서 반영 후 `Stage npm package`가 파일을 다시 생성한다면 그 새 파일에
exact-artifact 및 동일 파일 consumer 검사를 적용해야 한다. GIF와 사용자 가이드는
npm tarball에 포함되지 않으며 README는 GitHub의 GIF를 참조한다.

npm stage/publish, 버전 태그와 GitHub Release 생성은 이 문서 갱신에 포함하지 않는다.
