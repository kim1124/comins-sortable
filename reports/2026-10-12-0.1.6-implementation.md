## Failure classification

- Initial Firefox/WebKit launch failures were missing executables for the
  installed Playwright version. Matching engines were installed; product code
  was not changed for that environmental failure.
- The stationary-scroll test initially sampled activation before the pending
  pointer delta was applied. It now settles actual movement before measuring
  stationary scroll; the unchanged pointer position is asserted afterward.
- A table fixture's Firefox handle center was at y=722.9 in a 720px viewport;
  no lifecycle event occurred. A 1100px viewport and actual-source hit assertion
  fixed the fixture contract. The in-progress Playground run was interrupted
  while correcting this test, then the affected full gate was restarted.

## Remaining boundaries

The tested CSS `transform` translation/scale/planar-rotation, filter and
containment cases are verified; this is not certification of every CSS
transform pipeline or detached-preview rotation combination. Nonlinear 3D
perspective, transforms changed during an active drag and consumer clipping
rules are not a new support promise. Native Safari and physical Galaxy tests,
keyboard sorting, virtualization and new public options remain excluded.
Resource bounds are finite observations, not proof that every long-lived leak
is absent. New release versions and external integration remain separate.
