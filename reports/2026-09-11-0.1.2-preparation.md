## 커밋과 변경

- `2a635b6`: 누적 0.1.2 기능·결함 수정·Playground·문서·테스트 87개 파일 커밋.
- `b8e4308`: `origin/main`의 `0be429d`를 충돌 없이 로컬 작업 브랜치에 병합.
  v1.8과 기존 구현을 유지하고 Dependabot 설정 및 채택 리포트를 포함했다.
- 후속 준비 변경: CI 실행 조건, 회귀 테스트, SECURITY 공개 상태 정정,
  과거 검증 문서의 스냅샷 표시, 이 준비 기록.
- 기존 두 리포트의 로컬 계정 경로를 저장소 기준 표기로 정리했다.
- `.playwright-cli/`와 `reports/2026-07-27.md`는 별도 기존 산출물로 보존하고 제외했다.

성능 설정 파일만 변경하면 분류 결과가 `package=true`, `browser=false`,
`performance=true`여서 선행 Browser 잡이 선택되지 않는 결함을 재현했다.
Browser 경로 목록에 `playwright.performance.config.ts`를 추가했다.
임시 Git 저장소에서 실제 워크플로 Bash 본문을 실행하는 회귀 테스트는
수정 전 실패, 수정 후 통과했다. 패키지 런타임에는 추가 변경이 없다.

- 기존 scan: `381aece0-3755-45f0-9e8a-a64a875fb439`.
- 고정 범위: `0be429da2e7610caf5240684f89627d514768e7b` →

- 기본 변경 소스 목록 20개와 Playground 16개, CI·lockfile을 검토했다.
  독립 아키텍처·Core·어댑터 검토 결과와 임시 증거를 보존했다.
- 최종 draft 저장에 도구가 관리하는 범위 필드를 전달하여 인자 검증이 실패했다.
  뒤이은 완료 요청도 아래 오류로 실패했다. 완료된 보안 보고서로 간주하지 않는다.

  `The latest saved scan draft is incomplete; continue the scan before completing it.`

- 도구 지침에 따라 같은 응답에서 완료 호출을 재시도하지 않았다. 새 scan을
  생성하지 않고 기존 draft를 복구한 뒤 완료 처리해야 한다.
- 이후 CI 한 줄 보완은 별도로 diff 검토와 회귀·정책 검사를 수행했으며,
  위 고정 범위의 보안 검토에 포함했다고 주장하지 않는다.
- Daybreak 상태는 `not_granted`, 프로그램은 없음이다. 보호된 결과 표시가
  제한될 수 있으며, 이것이 완료 오류의 원인이라는 증거는 없다.

## 원격 상태와 다음 단계

1. 공개 npm 조회: versions/latest는 `0.1.1`, `0.1.2`는 미게시.
   열린 PR은 Dependabot #21, #22, #23이며 이번 기능 PR은 아직 없다.
2. 기존 보안 scan의 최종 draft 저장·완료 처리를 복구하고 결과를 확인한다.
3. 승인 후 브랜치를 push하고 main 대상 PR을 생성한다. 제안 제목:
   `feat: prepare sortable 0.1.2 interactions and playground fixes`.
4. 원격 CI 확인 후 별도 승인으로 main 반영. 실제 게시 시 release 정책,
   trusted publisher·npm 환경 및 신원을 확인하고 검증된 artifact를 사용한다.
   npm staging/publish, 2FA, 태그·Release는 별도 승인 단계다.

원격 push, PR 생성, main 반영, workflow dispatch, npm stage/publish, 태그·Release는
수행하지 않았다. CHANGELOG는 게시 전까지 Unreleased를 유지했다.
실제 터치 기기와 Safari의 OS 보조키를 누른 채 클릭하는 입력은 직접 검증하지
않았다. 다중 선택·메뉴 판정은 unit 및 세 브라우저 자동 검증에 포함된다.
