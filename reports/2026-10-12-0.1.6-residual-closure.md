# 0.1.6 잔여 정리

Date: 2026-10-12 (KST).

## 범위와 결과

- 공개 0.1.6의 배포 종료 문서만 원격 PR에 반영합니다.
- 로컬 Governance 커밋·설정은 공개 PR에서 제외합니다.
- 미추적 작업 기록은 로컬 전용 커밋 `f5094da`로 보존했습니다.
- 실기기 Safari/Galaxy, 키보드 정렬, 3D 및 제스처 중 transform 검증은
  유지관리자가 이번 작업에서 명시적으로 제외했습니다.
- 제품 소스·테스트 계약·배포 아티팩트를 변경하지 않았습니다.

## Svelte 측정 해석 정정

최초 로컬 실행의 DOM 카운터 +204 실패를 메모리 누수 발견으로 해석하지
않습니다. 동일 소스 재검사와 원격 리소스 게이트 및 대용량 벤치마크는
통과했습니다. 원래 실패 기록은 보존합니다.

후속 임시 진단은 세 실행에서 화면/live DOM·리스너 수가 유지되는 동안
첫 GC 직후 766개 또는 562개, 추가 GC 이후 562개를 관측했습니다.
같은 204개 차이를 확인했지만 내부 객체의 보유 원인까지 확정하지 않았습니다.
이 측정으로 제품 누수를 주장하지 않습니다. warm 샘플만 다른 시점에
수집하는 임시 진단은 중단했으며 추적된 테스트로 채택하지 않았습니다.
임시 진단 코드는 공개 변경에 포함하지 않습니다.

## 브랜치 삭제 안전성

- 직접 병합된 브랜치는 최신 원격 main에 대한 ancestry와 unique commit 0개 확인.
- PR #24의 `codex-0.1.2-quality-verification`은 squash commit `a176f039`과
  branch tree가 동일하며 squash commit이 main에 포함되어 있습니다.
- PR #26의 `codex/0.1.2-documentation`도 squash commit `ef7110a2`와
  branch tree가 동일하며 squash commit이 main에 포함되어 있습니다.
- 열린 PR이 없으며, 활성 worktree는 기본 checkout 하나입니다.
- 삭제 전 브랜치 tip과 복구 bundle을 무시된 로컬 증거 폴더에 보존합니다.
- 기본 main, 로컬 전용 지침, node_modules/dist 및 기존 검증 증거는 보존합니다.

## 검증

관련 user-docs/sensitive-data 계약 검사 18개와 diff hygiene가 통과했습니다.
제품 코드가 바뀌지 않았으므로 기존 release source의 전체 게이트 성공을
재사용하고, 종료 문서 PR의 현재 head CI를 별도로 확인합니다.
