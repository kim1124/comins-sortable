## 변경 범위

이번 패치 릴리즈는 Vanilla의 빈 목록 footer 경계, Vue SFC 타입 추론과
readonly/frozen 배열 rollback을 수정하고 애니메이션 비활성화 시 위치 측정과
레지스트리 ID 수집을 개선한다. 공개 API 추가·삭제 및 필수 마이그레이션은 없다.
구현·브라우저·성능 검증 범위는 [구현 기록](./2026-10-04-next-quality.md)과
[성능 기록](../docs/verification/next-quality-performance.md)을 참고한다.

이번 준비 변경은 package.json, package-lock.json의 루트 버전, 버전 고정 검사
2건, CHANGELOG, 문서 색인 및 이 기록에 한정한다. 의존성 해석·peer 범위·exports와
제품 코드는 변경하지 않는다. CHANGELOG에는 실제 공개일을 미리 기록하지 않는다.
README GIF는 기존 UI를 설명하는 촬영본을 유지하며 새로 촬영한 것으로 표기하지 않는다.

## 이후 단계와 잔여 범위

준비 PR 병합과 npm staging/공개는 별도 승인 단계다. 승인된 main을 기준으로
publish.yml에서 정식 파일을 만들고 allow-list·라이선스·민감정보 검사 및 동일
tgz 소비자 검증을 수행한다. 기존 0.1.4 로컬 파일을 0.1.5의 정식 artifact로
재사용하지 않는다. 공개 뒤 latest·무결성·provenance·소비자 결과와 실제 공개
시각을 별도 기록하고 문서 색인을 갱신한다.

키보드 정렬·Galaxy 실기기 검증은 제외 범위를 유지한다. Native Safari를 이번에
재검증한 것으로 주장하지 않는다. 측정된 성능 개선은 해당 조건에 한정되며 모든
드롭 지연 개선 또는 모든 장기 메모리 누수 부재를 의미하지 않는다.
