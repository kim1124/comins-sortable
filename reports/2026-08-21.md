# 2026-08-21 Comins Sortable Copy 및 Clone Playground

## 작업 일시

- 2026-08-21 (Asia/Seoul)

## 요약

- Governance 저장소의 최신 계약이 Contract v1.6임을 확인하고, 활성 worktree의
  managed `AGENTS.md` 블록과 `.codex/config.toml`을 동기화 명령으로 재검증했다.
- 기존 string `group`의 move 동작을 유지하면서 object `group`의 `pull`/`put`,
  `move | copy` 전송 모드와 pointer modifier snapshot을 Core에 추가했다.
- copy change가 원본 order를 보존하고 새 ID만 대상 order에 삽입하도록 immutable
  operation과 commit verification을 구현했다.
- Vanilla에는 `copyElement(source, context)`, React/Vue/Svelte에는
  `copyItem(item, context)` typed factory를 추가했다. factory 오류, 누락 ID, 중복 ID,
  callback 실패 및 commit 불일치는 기존 cleanup-first rollback 경로를 사용한다.
- Playground에 `Clone`, `Custom Clone`, `Clone on Control` route를 네 adapter의 실제
  public API로 추가하고 parity 표시를 9/17로 갱신했다.
