- 작업 일시: 2026-09-11 15:15~15:24 KST
- 작업 브랜치: `codex/0.1.2-release-closure`
- 공개 소스: `ef7110a2af7b6853abe882ff1cddf4c1c9418696`, PR #26
- 기준: Comins Contract v1.8, Release Policy

## 수행 결과

0.1.2가 공개된 것을 확인해 승인 명령을 중복 실행하지 않았다. 공개 exact version과
`latest`는 0.1.2이며, registry 공개 시각은 `2026-09-11T06:15:02.892Z`다.

Stage 실행 `34568091733`의 성공 파일과 공개 tarball은 바이트 단위로 동일하다.
SHA-256은 `fdf1d894a65fed1bdffb71856b1ef7633f4b846f503d4f92453cd7b565885268`이다.
registry shasum·integrity 일치, 격리된 설치의 `npm audit signatures`, provenance의
파일 해시·소스 커밋·워크플로·실행 ID 검증, 공개 tarball consumer 검사가 통과했다.
consumer는 React/React DOM 18.2.0, Vue 3.5.0, Svelte 5.0.0의 최소 지원 조합이다.

Stage의 current maintainer 검사와 공개 후 identity 검사를 구분한다. 후자는 이전에
승인·검증된 0.1.1 bootstrap publisher를 기준으로 기존 검사 함수로 maintainer,
GitHub trusted publisher 및 approver를 검증했다. 신원 값은 기록하지 않았다.

공개 소스의 보호된 main 및 병합 후 CI `34567546814` 성공을 확인했다. 로컬 main은
origin/main의 공개 소스 커밋으로 fast-forward했으며, 후속 문서는 별도 로컬 브랜치에서
작성했다. 전체 Stage 검사 결과와 공개 근거는
[배포 검증 기록](../docs/verification/0.1.2-release-candidate.md)에 추가했다.

## 검증 및 잔여 상태

로컬 문서·버전 assertion 변경 후 `npm run verify`와 diff 검사가 통과했다.
라이선스, 정책 51/51, 단위 249/249, TypeScript, build, 공개 타입 검사를 포함한다.
런타임·의존성·워크플로 변경은 없다. Stage에서 통과한 E2E 238개와 Playground
279개는 공개 소스에 대한 기록이며, 이번 문서 변경의 재실행 결과로 취급하지 않는다.

현재 release는 **Published**다. 후속 문서의 원격 반영과 보호된 main 병합 및 CI 확인이
남아 있으므로 **Closed**로 보고하지 않는다. 공개된 0.1.2 tarball에는 Stage 당시
README 후보 문구와 CHANGELOG Unreleased 표기가 고정되어 있으며 파일을 교체하지 않았다.

새 태그·GitHub Release, 추가 버전, 브랜치·worktree·기존 작업 파일 삭제는 수행하지 않았다.
기존 `codex-0.1.2-quality-verification`, `codex/0.1.2-documentation` 브랜치 및
미추적 `.playwright-cli/`, `reports/2026-07-27.md`를 보존했다. 실제 Safari·터치·펜
검증 범위도 이전 기록에서 확대하지 않았다.

## README 및 검색 메타데이터 보완

사용자 피드백에 따라 README를 제품 소개·기능·설치·예제·API 안내 중심으로 정리했다.
신원 사고, 내부 배포 승인, 거버넌스 운영 절차와 세부 검사 보고는 README에서 제거했다.
과거 검증 기록과 정책 문서는 별도로 보존한다. 현재 공개 버전은 0.1.2로 표시한다.

`package.json`에 제품 설명과 sortable, drag-and-drop, framework, list/grid/tree,
multi-drag, swap 등 실제 기능에 해당하는 검색 키워드 17개를 추가했다.
오프라인 lockfile 동기화 후 변경이 없음을 확인했다. 의존성·런타임·exports는 동일하다.
보안 테스트에서 README의 운영 정책·툴 이름 표기를 강제하던 assertion과 문서 테스트의
내부 parity 수 표기 assertion을 정리했다. 실제 보안 gate·버전·peer·문서 링크 검증은 유지한다.

GitHub 설명과 Topics도 같은 제품 설명 및 키워드로 갱신할 수 있도록 준비한다.
현재 npm 0.1.2의 README와 메타데이터는 소스 수정만으로 바뀌지 않는다.
[npm README 정책](https://docs.npmjs.com/about-package-readme-files/)에 따라 npm 페이지
반영에는 새 버전 배포가 필요하며, 이 수정에서 버전 변경·재배포는 하지 않았다.

최종 수정 후 `npm run verify`의 라이선스·정책 51/51·단위 249/249·타입·빌드·공개 타입
검사가 통과했다. README에 0.1.0/0.1.1 안내, 사고 이력, 내부 승인 및 거버넌스 문구가
없고 0.1.2를 표시하는지 확인했다. GitHub 설명·Topics 갱신과 소스 push는 아직 미실행이다.
