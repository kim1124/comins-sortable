# 2026-08-08 Immutable Sortable Operations

## 작업 일시

- 2026-08-08 (Asia/Seoul)

## 요약

- 승인된 Comins Sortable v1 구현 계획의 Task 2를 구현했다.
- readonly 입력을 직접 변경하지 않는 `reorder<T>()`와 `transfer<T>()`를
  `./core` 공개 API에 추가했다.
- 동일 위치 재정렬은 기존 배열 참조를 유지하고, 실제 변경은 영향받는
  배열만 얕게 복사한다.
- 비공개 change builder는 reorder order 한 개 또는 source 이후 destination
  order 두 개를 조립하며, 동일 영역 no-op은 change를 생성하지 않는다.
- 정수가 아니거나 허용 범위를 벗어난 인덱스는 값 노출 없이
  `RangeError`로 거부한다.
- 의존성, package boundary, 원격 상태는 변경하지 않았다.
