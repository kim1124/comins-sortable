# Task 3: Scope Registry, Geometry, And Collision

## 작업 일시

- 2026-08-08 (Asia/Seoul)

## 요약

- Scope별 `AreaRegistry`를 추가해 area ID와 group별 item ID를 검증하고,
  element lookup은 `WeakMap`으로 유지했다.
- registry는 동일 `ownerDocument`만 허용하며, idempotent unregister 시 Map과
  WeakMap lookup을 해제하고 마지막 area 제거 시 document 참조도 해제한다.
- structural Element의 rect snapshot, explicit/auto direction 판정, cached
  midpoint용 binary-search insertion index와 empty-area hit fallback을 추가했다.
- collision은 inner direct hit 우선순위를 보존하고 disabled, group, accept
  조건을 통과한 area만 선택한다. 빈 area의 threshold 확장은 zero primary axis에만 적용한다.
- Core public barrel, package export, 의존성, 원격 상태는 변경하지 않았다.
