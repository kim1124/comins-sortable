- 공개 `createSortableScope()`와 area 등록·갱신·해제 계약을 추가했다.
- same-tag empty Placeholder, source feedback, focus·inline style 복원 및 영역 간 이동과

  rAF scrolling, 종료 시 frame cleanup을 구현했다.

  이동·framework update 시점에만 필요한 rect를 갱신하도록 했다.
- `before → start → drag → insert → change → after` 순서, 다음 rAF commit 확인,
  `state-not-committed` rollback 및 고정 status mapping을 구현했다.

  commit 확인 대기 중 취소를 각각 승인된 cleanup 순서로 처리했다.
- 첫 public area 등록 실패 후 platform이 잘못 고정되지 않도록 초기화 transaction을
  보완하고, destination `accept`를 pointer frame당 한 번만 평가하도록 했다.
