# 0.1.6 grid collision follow-up

Date: 2026-10-12 (KST). Approved scope: grid correctness, four-adapter regressions,
direct interaction, PR #40 update and resumed staged publication after passing.

## Reproduction and cause

Native desktop Chrome exposed the same behavior in Vanilla, React, Vue and
Svelte at candidate 535ebe5. With 136px cell spacing, a left-handle rightward
136px move aligned the card center with the next cell but retained index 0;
176px crossed the pointer midpoint and finally reordered. A same-column row
move inserted at index 7 instead of 8. Collision code was unchanged since
published 0.1.5. Evidence is preserved separately in ignored local grid-review
screenshots and seven observation records.

## Change

Cache the grabbed card center relative to the press origin at activation.
Use that center for grid insertion and placeholder stability. Resolve rounded
center ties against the prior insertion index. Actual pointer area hits,
acceptance, scroll and target-swap remain unchanged; no new public API or
runtime dependency. Changes cover Core collision/scope, unit/Playground tests,
README/CHANGELOG, English/Korean sorting guides and Playground description.

## Verification

Before production edits, all four Chromium right-one-cell regressions failed
with expected insertion 1 versus actual 0. The midpoint unit regression also
failed. After correction, the focused three-engine grid/swap suite passed 60
cases. Final fresh-candidate gates and native interaction remain pending.
