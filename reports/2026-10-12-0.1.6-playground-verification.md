# 0.1.6 Playground 직접 검증 및 도구 오류 분류

작업 일시: 2026-10-12 (KST). 검증 소스: `4cc4761a71d5e236afdaf1e3ce602d0cbdde6978`.

## 결과

0.1.6 수정 사항의 실제 Playground 상호작용 44개가 통과했습니다.
초기 iframe 관측 오류는 아래 대조 실험에 따라 **제품 이슈에서 제외**합니다.
제품 코드·테스트 계약·의존성·workflow·공개 0.1.6 패키지를 변경하지 않았습니다.

현재 소스를 별도 사본에 두고 `npm ci --ignore-scripts`를 실행한 Vite 8.3.4
개발 서버를 사용했습니다. 처음 열려 있던 캐시 화면의 결과는 최종 집계에서
제외하고, 서버 재실행 후 새로 로드한 화면의 결과를 기록합니다.
이 설치와 화면 검증을 전체 자동 게이트 재실행으로 표현하지 않습니다.

| 확인 범위 | 결과 |
| --- | --- |
| Vanilla/React/Vue/Svelte × 그리드 우/좌/하/상 | 16 통과 |
| 네 어댑터 × CSS·복제 조건 7개 | 28 통과 |
| 최대 위치 오차 | 약 0.006165 px |
| 최대 크기 오차 | 약 0.004639 px |
| 종료 후 드래그/placeholder 표시 | 모든 경우 0개 |
| 일반 Playground 콘솔 오류 | 0개 |

그리드는 실제 화면의 2열 배치에서 왼쪽 핸들로 카드 중심을 한 칸 옮기고
최종 삽입 위치, 모델/DOM 순서 일치, drop 종료 및 표시 제거를 확인했습니다.

CSS 조건은 회전+축소 이동, 축소 이동, 축소 원본 복제, body+원본 이중 축소
복제, contain:paint, filter, 일반 이동입니다. 기존 진단 wrapper가 실제
Playground iframe에 소비자 CSS만 적용하고 네이티브 포인터 입력을 관측했습니다.
합성 drag/drop이나 앱 모델 변경은 사용하지 않았습니다. 실제 `todo/design`
시작, live `done` hit, 프레임 좌표/크기, 최종 모델과 DOM, drop, cleanup을
확인했습니다. 복제에서는 원본 Design이 남고 `design-copy-1`이 생성됐습니다.
이는 기본 UI 그리드 관측과 구분되는 CSS 재현 조건이며 새 제품 예제가 아닙니다.

## 초기 MutationObserver 오류: 제품 이슈에서 제외

오류는 `MutationObserver.observe()`에 DOM Node가 아닌 관측 대상을 전달한
TypeError입니다. 검증 wrapper를 처음 열 때 한 번 기록됐습니다.

| 대조 조건 | 결과 |
| --- | --- |
| 일반 Playground | 오류 없음 |
| 순수 HTTP 서버의 정적 HTML, iframe 없음 | 오류 없음 |
| 같은 정적 child HTML을 단독으로 열기 | 오류 없음 |
| 순수 HTTP 서버의 정적 iframe, 독립 새 탭 2개 | 각각 동일 오류 1건 |

마지막 두 iframe 재현에는 Sortable·wrapper·프레임워크·Vite가 없고, 부모와
자식 문서의 JavaScript 수는 각각 0개였습니다. 페이지에서 observe를 호출하지
않으므로 이 오류를 제품이나 wrapper 구현의 결함으로 분류하지 않습니다.
**검증 브라우저의 iframe 초기 관측 환경 문제**로 분류합니다.
도구 내부 호출 스택·함수·파일·라인은 제공되지 않아 세부 원인은 미확정입니다.
제품 수정 대상에서 제외하는 것과 도구 자체의 수정 완료는 구분합니다.
이 오류는 기존 44개 상호작용의 통과 결과를 무효화하지 않습니다.

## 공개 증거와 미실행 범위

[개별 검증 결과](../docs/verification/evidence/0.1.6-playground-2026-10-12.json)에
16개 그리드 결과와 28개 CSS 결과, 오차·모델/DOM·종료/cleanup 및 오류 대조를
기록했습니다. 공개 px 수치는 소수점 6자리로 반올림하고 원래 정밀도의
측정값은 로컬에 보존합니다. 원본 스크린샷·프레임별 관측·최소 재현 HTML은 무시된 로컬 증거에
보존하고 공개 파일에는 개인 경로·프로필·내부 도구 출력 등을 포함하지 않습니다.

유지관리자가 제외한 실기기 Safari/Galaxy, 키보드 정렬, nonlinear 3D 및
드래그 중 transform 변경은 확인하지 않았습니다. table-tag fixture도 이번
공개 Playground 결과에 포함하지 않습니다. 성능·메모리는 새로 측정하지 않았습니다.

문서 PR과 병합 후 main의 보안 CI는 별도로 확인합니다.
