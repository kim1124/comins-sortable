## 반영 내용

Vanilla의 외부 빈 목록 footer 경계를 수정하고 Vue SFC 타입 추론과
readonly/frozen 배열 rollback을 보완했다. Core는 애니메이션 비활성화 시
위치 측정을 생략하고 같은 레지스트리 읽기 안에서 항목 ID를 재사용한다.
공개 API 마이그레이션은 없다. 세부 변경과 검증은
[구현 기록](./2026-10-04-next-quality.md),
[릴리즈 준비](./2026-10-04-0.1.5-release-preparation.md),
[성능 기록](../docs/verification/next-quality-performance.md)을 참고한다.

## 종료 문서와 잔여 범위

문서 색인의 latest를 0.1.5로 갱신하고 CHANGELOG에 실제 공개일을 추가했다.
준비 기록은 이력으로 유지하고 본 종료 기록을 연결한다. 이 문서 변경으로 제품
코드·의존성·공개 파일을 바꾸지 않는다. 종료 문서의 로컬 커밋과 원격 반영은
공개 패키지의 검증 결과와 구분한다.

키보드 정렬·Galaxy 실기기 검증은 제외 범위를 유지한다. 실제 Safari 제목
드래그의 본문 선택 잔상은 해결됐다고 주장하지 않는다. 성능 수치와 리소스
검증은 기록된 조건에 한정되며 모든 드롭 지연 개선 또는 모든 장기 누수 부재의
증거가 아니다. 작업 브랜치와 로컬 증거는 보존하며 삭제하지 않는다.
