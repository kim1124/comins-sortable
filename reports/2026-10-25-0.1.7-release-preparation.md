# 0.1.7 배포 준비 — 2026-10-25

## 범위와 변경

로컬 0.1.7 후보 준비이며 미게시다. 제품 기준 HEAD는 `4fcdba1`이다.
제품 소스·의존성 버전은 변경하지 않았다. 기존 미추적 Safari 조사 자료는 보존했다.
기존 renderer·메모리 수정·핸들 선택 억제를 0.1.7 CHANGELOG로 정리했다.

- `package.json`, `package-lock.json`: 0.1.7 및 npm version lifecycle.
- `scripts/sync-release-docs.mjs`, `test/release-docs.node.mjs`: CHANGELOG의 영문·국문
  요약과 검증 상태 문서에 기반해 README 상단·문서 인덱스·최신 변경 문서 생성.
  누락된 번역/버전/검증 문서, 손상된 마커는 쓰기 전에 거부한다. npm version의
  다음 버전 fixture와 불일치 검출·멱등성도 확인했다.
- `.github/workflows/verify.yml`: 의존성 설치가 필요 없는 Docs job 추가.
  문서만 바뀐 경우에도 동기화 검사를 수행한다. 이 원격 job은 아직 실행하지 않았다.
- README·문서 인덱스·영문/국문 copy/handle/placeholder/lifecycle/API 가이드·
  Playground 안내와 현재 검증 안내를 갱신했다. 과거 날짜의 검증 보고서는 보존했다.
- 패키지 경계 정책 검사의 하드코딩된 과거 버전 대신 manifest·lockfile 일치를 검사한다.

## 검증 방식

기존 개발 폴더와 실행 서버를 보존했다. HEAD의 독립 clone에 현재 파일 337개의
미커밋 overlay를 복사하고 SHA-256 manifest를 보존했다. 생성물·node_modules 없이
시작해 `npm ci --ignore-scripts` 후 `npm run verify`를 실행했다. 공유 node_modules는
사용하지 않았다. 따라서 이것은 새 커밋의 검증이 아니라 명시된 overlay의 검증이다.

라이선스·민감정보 정책은 기존에 검증된 Governance v1.12의 깨끗한 사본에서 읽었다.
현재 Governance 작업 폴더의 v1.13 미커밋 변경은 적용하지 않았다. 로컬 v1.12 채택은
미게시 상태이며 이번 작업에서 공통 정책을 변경하지 않았다.

## 한계와 다음 단계

[0.1.7 검증 상태](../docs/verification/0.1.7-local-validation.md)의 Safari DOM 보유
판정과 알려진 동적 transform 제한을 유지한다. 현재 Vue 의심 건은 Inspector/Reader의
보유·회수 경로로 귀속되며 새로운 Vue 제품 수정은 없다. 모든 메모리 경로의 무누수
인증은 아니다. 드래그 중 transform 변경은 실패가 확인된 별도 제한이며 해결하지 않았다.

커밋·원격 push·PR·CI·staging·npm publish·태그·GitHub Release는 수행하지 않았다.
원격 반영 전에 모듈 절차에 따라 후보 커밋을 고정하고 동일 후보의 검증 경계를 확인해야
한다. 실제 게시 시에는 canonical staging·provenance·registry·소비자·배포 마감이 남는다.
