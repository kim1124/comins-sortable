## 요약

- Playground의 전체 route 수와 Vue.Draggable parity 구현 수가 같은 값으로 표시되던
  문제를 수정했다.
- 현재 route는 9개지만 parity 계약을 구현한 route는 6개다. Empty Destination,
  Accept/Reject, Auto Scroll은 별도 Comins 예제다.
- Safari와 physical touch/pen은 자동화된 Playwright WebKit 결과로 인증하지 않도록
  README에 browser evidence 경계를 추가했다.
- Core의 primary touch·pen pointer에 activation, move, release, capture cleanup 단위
  계약을 추가했다. 이는 synthetic coverage이며 실제 장치 인증을 대체하지 않는다.
- 기존 `codex/sortable-task4` worktree의 유실된 `.git` 연결과 누락 tracked 파일을
  복구했다. 사용자 수정 `test/playwright/helpers/drag.ts`는 그대로 보존했다.
- Safari 26.6 `safaridriver` 서버는 기동했지만 실제 session 생성은 Safari 설정의
  `Allow remote automation` 비활성화로 차단됐다. `safaridriver --enable`은 실행하지 않았다.
